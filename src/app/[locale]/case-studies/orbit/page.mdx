# Orbit

**Orbit** is an interactive 3D web application that simulates the solar system and tracks Near-Earth Objects (NEOs). We built it for the **NASA Space Apps Cairo 2024** hackathon with **Next.js** on the frontend, **Three.js** for 3D rendering, and **Go** on the backend. The project stays open-source so contributors can extend its orbital tools and visual features.

---

## High-Level Summary

Orbit brings live NASA orbital datasets into the browser for students, researchers, and space enthusiasts. Users explore celestial bodies, inspect orbital paths, and track Near-Earth Objects (NEOs) and Potentially Hazardous Asteroids (PHAs) in a live 3D simulation.

Visitors can inspect individual object trajectories, read Keplerian orbital metrics, and save favorite NEOs in a personal dashboard.

---

## Project Details

### 1. NEO Management

- **NEO Database Integration**: Syncs with NASA's **Small Body Database** to pull current parameters for tracked NEOs and Potentially Hazardous Asteroids (PHAs).
- **Scheduled Data Refreshes**: The Go backend refreshes cached orbital records on a schedule to capture revised trajectories and new discoveries.
- **Detailed Object Pages**: Each NEO has a dedicated profile listing Keplerian parameters (eccentricity, semi-major axis, inclination) alongside its plotted trajectory.

### 2. 3D Visualization with Three.js

- **Interactive Orrery**: Built in **Three.js** with zoom, rotate, and pan controls for navigating live planetary and asteroid orbits.
- **Time Controls**: Users step forward or backward through time to inspect past positions and upcoming close approaches.
- **Camera Perspectives**: Switch between wide orbital views and a first-person flight perspective across the solar system.

### 3. Visit Tracking

- **Session Keys**: Each visit generates a unique session key to log explored objects and interaction paths.
- **Exploration History**: Returning visitors can jump back to objects and timestamps reviewed in prior sessions.

## Use of Artificial Intelligence

Orbit pairs two AI integrations for user education and orbital math:

### 1. Gemini API for the Space Chatbot

We integrated the **Gemini API** to answer plain-language questions about the solar system, orbital terms, and tracked asteroids.

- **Direct Q&A**: Users ask questions such as "What is the current position of asteroid XYZ?" or "Which NEOs pass closest to Earth this month?" and receive structured answers grounded in curated data.
- **Astronomy Glossary**: Explains orbital mechanics terminology for newcomers exploring the orrery.

### 2. Claude for Orbital Computations

We paired the backend with **Claude** to assist with heavy orbital calculations without stalling the browser.

- **Orbital Propagation**: Applies Keplerian elements to project future NEO positions and flag close-approach windows.
- **Background Computation**: Offloads intensive trajectory analysis from the UI thread so 3D frame rates stay responsive.

---

## Space Agency Data

Orbit pulls orbital parameters from NASA's public **Small Body Database (SBD)**.

- **Keplerian Elements**: Plots trajectories from eccentricity, inclination, and semi-major axis values.
- **Ongoing Sync**: The backend refreshes SBD records on a regular cycle to include new NEO entries and updated orbital elements.

## Hackathon Journey

### 1. Planning Phase

We scoped features we could finish inside the hackathon window: responsive 3D navigation, live NEO lookup, and AI-assisted Q&A over NASA datasets.

### 2. Development Phase

We split execution into two parallel tracks:

- The **frontend** team built the **Next.js** interface and the **Three.js** orrery.
- The **backend** team built the **Go** API, NASA Small Body Database ingestion, and session tracking.

### 3. Engineering Tradeoffs

Our main bottlenecks were syncing live orbital updates into the 3D scene, cutting chatbot latency, and keeping heavy trajectory math off the main thread. Caching queried records and offloading intensive computation kept rendering smooth.

### 4. Testing and Optimization

We tested frame rates and gesture controls (zoom, pan, rotate) across desktop and mobile browsers before submission.

## Installation

### Prerequisites

- **Go**: Version 1.23.0 or higher
- **Node.js**: Latest LTS release for the frontend
- A configured database instance (PostgreSQL or MySQL)

### How to Run the App

1. Install dependencies:
   ```bash
   bun install
   ```
2. Start the development server:
   ```bash
   bun run dev
   ```
