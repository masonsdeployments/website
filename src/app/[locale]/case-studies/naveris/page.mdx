# NAVERIS

## Project Overview

We built NAVERIS during the **NASA Space Apps Cairo 2023 Hackathon** as an early warning system for natural disasters. The platform runs machine learning models over meteorological and environmental feeds to forecast severe events ahead of landfall.

## Project Mission

NAVERIS gives local communities and emergency teams lead time before severe weather strikes. The system analyzes atmospheric pressure, wind speed, wind direction, and regional patterns to issue early alerts that reduce casualties and property damage.

## Technical Implementation

### Mapping with DotMatrix

#### Dot Matrix Generator System

The Dot Matrix Generator builds coordinate-based environmental maps from live sensor feeds:

- **Generates coordinate points** mapped by latitude and longitude.
- **Collects live meteorological telemetry** covering atmospheric pressure, wind speed, and wind direction.
- **Outputs structured JSON** formatted for the prediction pipeline.
- **Renders dot projections** that plot regional weather systems across a map grid.

#### Data Structure

Each captured sensor reading follows this JSON schema:

```json
{
  "id": "1",
  "lat": "46.2102",
  "lon": "-38.8989",
  "ws": "43.38",
  "wd": "319",
  "ap": "1010"
}
```

**Field Descriptions:**

- `id`: Unique identifier for the reading.
- `lat`: Latitude coordinate in decimal degrees.
- `lon`: Longitude coordinate in decimal degrees.
- `ws`: Wind speed in km/h or mph.
- `wd`: Wind direction in degrees (0-360).
- `ap`: Atmospheric pressure in millibars.

#### Data Collection Network

The ingestion layer monitors thousands of coordinate points across geographic regions and writes live updates into `dotMatrix.json` for downstream risk scoring.

## System Architecture

### Data Processing Pipeline

1. **Data Collection**: Ingests live meteorological and seismic readings.
2. **Data Validation**: Runs schema checks and flags sensor anomalies.
3. **Pattern Analysis**: Machine learning models detect disaster precursors.
4. **Risk Assessment**: Computes event probability scores per disaster type.
5. **Alert Generation**: Dispatches automated warnings to emergency teams and affected areas.

### Technology Stack

- **Backend**: Python data processing and machine learning models.
- **Data Storage**: Structured JSON datasets with live updates.
- **Mapping**: Geographic Information System (GIS) integration.
- **API**: REST endpoints for telemetry access and alert distribution.
