# repAI: Recycling Rewards Platform

**AI-Powered Recycling Rewards**  
**Built for AI Finance Hackathon 2025 by GDG Cairo (Top 7)**

---

## Project Overview

repAI is a web application that pays users cashback for recycling. The platform identifies recyclable materials from photos and receipts, quotes live material prices, connects households with local collectors, and credits rewards once pickup completes.

---

## Key Features

- **AI Object Detection**: Scans household items through the **Google Gemini API** to classify recyclable material types and estimate payout value.
- **Receipt Scanning**: Extracts recyclable packaging lines from shopping receipts via the **Google Image API**.
- **Dynamic Cashback Pricing**: Calculates cashback payouts from live material rates and logged drop-off volume.
- **Reward Redemption**: Lets users spend earned balances with participating eco-focused partner merchants.
- **Recycling Marketplace**: Lists verified companies that purchase recycled stock or use recovered materials in manufacturing.
- **Protected Accounts**: Secures sign-in and reward claims with **Firebase Authentication** and **reCAPTCHA**.

---

## Technology Stack

- **Frontend**: Angular
- **Backend**: Go (Golang)
- **AI / Vision APIs**:
  - Google Gemini API (Object Detection)
  - Google Image API (Receipt Scanning)
  - Imagen 3 (Image Processing)
- **Hosting**: Google Cloud Platform (GCP)
- **Database**: Firebase Firestore
- **Authentication**: Firebase Authentication + reCAPTCHA
- **Rewards Engine**: Custom cashback pricing and payout ledger

## Local Setup

### Prerequisites

- Go (v1.20 or higher)
- Angular CLI (v15 or higher)
- Firebase CLI
- Google Cloud SDK

### Installation Steps

1. Clone the repository and install both frontend and backend dependencies.
2. **Configure Firebase**:
   - Create a project in the [Firebase Console](https://console.firebase.google.com/).
   - Add your Firebase config keys to the frontend environment.
   - Enable **Firebase Authentication** and **Firestore**.
3. **Configure Google Cloud**:
   - Enable the **Google Gemini API** and **Google Image API** in your GCP project.
   - Add API credentials to the Go backend configuration.
4. **Configure reCAPTCHA**:
   - Register the app domain in [Google reCAPTCHA](https://www.google.com/recaptcha/admin/).
   - Add the site key to the frontend configuration.
5. Start the frontend and backend services, then open `http://localhost:4200`.

## Deployment

repAI runs on **Google Cloud Platform** and **Firebase Hosting**:

1. **Build the Frontend**:
   ```bash
   cd frontend
   ng build --prod
   ```
2. **Deploy to Firebase Hosting**:
   ```bash
   firebase deploy
   ```
3. **Deploy the Go Backend on Google Cloud Run**:
   ```bash
   gcloud run deploy repai-backend --image=gcr.io/your-project-id/repai-backend
   ```
4. **Automate CI/CD**: Connect GitHub Actions or Google Cloud Build for automated staging and production releases.

## AI and Finance Pipeline

- **Classification**: **Google Gemini API** inspects uploaded item photos and assigns recyclable categories.
- **Receipt Extraction**: **Google Image API** parses store receipts for eligible packaging items.
- **Payout Calculation**: The Go pricing service applies current market rates per kilogram and updates user balances.
- **Redemption**: Verified balances convert into partner vouchers or cashback credits.
